# BaseStudio releases

This repository holds the releases of the BaseStudio desktop app: the installers for macOS (Apple Silicon), Windows and
Linux, and the update files that the app reads to update itself.

- **Download:** the [latest release](https://github.com/gabrielbacha/BaseStudio-releases/releases/latest), or the
  download section of [basestudio.dev](https://basestudio.dev/).
- **Documentation:** [basestudio.dev/docs](https://basestudio.dev/docs/).
- **Help:** [Get help](https://basestudio.dev/docs/reference/support/).

The source code of BaseStudio is private. This repository has no source code. The releases are made by the release
workflow of the source repository.
